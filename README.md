# Kliperin

Installer dan pembaruan otomatis aplikasi **Kliperin** (tempel link YouTube, jadi klip 9:16) untuk Mac dan Windows.

- Mac: `Kliperin-Mac.dmg`
- Windows: `Kliperin-Windows-Setup.exe`

Butuh kunci lisensi dari [kliperin.id](https://kliperin.id). Aplikasi bekerja di komputer kamu, tanpa akun.
